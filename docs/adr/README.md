# Architecture Decision Records

ADRs registram decisões arquiteturais **e o porquê delas**. Depois de *Aceito*, o conteúdo de um ADR
não é editado (exceto o status e correções de digitação). Para mudar a decisão, crie um novo ADR que o substitua.

## Ciclo de vida

`Proposto` → `Aceito` | `Rejeitado`. Depois: `Obsoleto` ou `Substituído por ADR-NNNN`.

- Agentes **podem** criar ADRs com status `Proposto`.
- Só humanos movem um ADR para `Aceito`, `Rejeitado`, `Obsoleto` ou `Substituído`.
